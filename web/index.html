EQ-BioDT v0.4

The Empty Quarter Digital Twin provides metagenomic evidence, conditional soil trace-gas scenarios and campaign-level capacity forecasts.

The interactive console runs with the Python service:

uv sync --locked
uv run eq-biodt serve --port 8000

Then open the local console or its interactive API.

Installation and source code · Release and manuscript

Process outputs depend on supplied kinetics and soil properties. The tool is a research prototype; genomic evidence measures capacity, and local flux calibration remains an experimental requirement.
