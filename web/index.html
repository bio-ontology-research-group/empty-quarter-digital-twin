EQ-BioDT v0.6

A causal–ontological digital twin of the Rub’ al-Khali. It links primary soil-metagenome evidence, OWL deduction of genome capabilities, a community factor, and paired do() regimes on a conditional soil process model. External transfer tests use Namib, Sonoran and temperate data.

The interactive console runs locally with the Python service:

uv sync --locked
uv run eq-biodt serve --port 8000

Then open http://127.0.0.1:8000 (API reference at /docs).

GitHub release · rubalkhali.science/model

Scenario outputs are conditional on supplied kinetics and soil properties; genomic evidence measures encoded capacity, not activity or carbon removal.
